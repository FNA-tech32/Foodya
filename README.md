# Foodya

Foodya is a one-page website for a premium meal-delivery service. It is a static site: HTML, CSS, and a small amount of JavaScript. There is no install step and no build.

## What's on the page

- **Food delivery** — subscription coverage, 20-minute delivery, organic ingredients, and an open menu
- **Meals** — a photo gallery of signature dishes
- **How it works** — pick a plan, order, and eat
- **Our cities** — Lisbon, San Francisco, Berlin, and London
- **Testimonials** — customer quotes
- **Sign up** — Premium, Pro, and Starter plans
- **Contact** — email, phone, address, and hours

## How to run it

Open `index.html` in a browser.

Or serve the folder so image and font paths load the same way they do on a host:

```bash
python -m http.server 8080
```

Then open [http://localhost:8080](http://localhost:8080).

## Files

| File | Role |
| --- | --- |
| `index.html` | The page |
| `resources/css/style.css` | Layout and look |
| `resources/css/queries.css` | Phone and tablet layout |
| `resources/js/script.js` | Sticky nav, scroll, and mobile menu |
